## Agentes comerciales (propietarios)
Son productos o plataformas desarrollados por empresas. Normalmente se utilizan mediante una aplicación, una suscripción o una API.

| Empresa    | Agente                           | Descripción                                                                                                       |
| ---------- | -------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| OpenAI     | ChatGPT Work                     | Agente para investigar, analizar, trabajar con archivos y aplicaciones y producir documentos y otros entregables. |
| OpenAI     | Codex                            | Agente especializado en programación, modificación de código y desarrollo.                                        |
| OpenAI     | Workspace Agents                 | Crear agentes compartidos para equipos y organizaciones.                                                          |
| Anthropic  | Claude Cowork                    | Realizar tareas de conocimiento, investigación, análisis y trabajos con archivos.                                 |
| Anthropic  | Claude Code                      | Agente especializado en programación.                                                                             |
| Anthropic  | Claude Managed Agents            | Infraestructura gestionada para ejecutar agentes de larga duración mediante API.                                  |
| Microsoft  | Copilot Studio                   | Crear agentes para automatizar procesos empresariales y conectar aplicaciones.                                    |
| Salesforce | Agentforce                       | Agentes orientados a ventas, atención al cliente y procesos comerciales.                                          |
| Google     | Gemini Enterprise Agent Platform | Crear, desplegar y gestionar agentes empresariales.                                                               |


## Agentes Open Source
Aquí encontramos proyectos cuyo código está disponible públicamente y que puedes instalar, ejecutar y, según su licencia, modificar.

#### Agentes personales y de propósito general

| Agente       | Descripción                                                                                                                                                                    |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| OpenClaw     | Agente personal de propósito general. Puede conectarse a Telegram, Whatsapp, Discord y otros canales, utilizar herramientas y trabajar desde tu propio ordenador o servidor.   |
| Hermes Agent | Agente personal desarrollado por Nous Research. Incluye memoria, aprendizaje de habilidades a partir de experiencias, automatizaciones u delegación de tareas a otros agentes. |

#### Agentes especializados en programación
| Proyecto  | Descripción                                                                                                                 | Licencia   |
| --------- | --------------------------------------------------------------------------------------------------------------------------- | ---------- |
| OpenCode  | Agente de programación que funciona principalmente desde la terminal y permite utilizar distintos proveedores de modelos.   | MIT        |
| OpenHands | Ecosistema para ejecutar y coordinar agentes de desarrollo mediante un centro de control authospedado llamado Agent Canvas. | MIT        |
| Cline     | Agente de programación para IDE, terminal y SDK.                                                                            | Apache 2.0 |
