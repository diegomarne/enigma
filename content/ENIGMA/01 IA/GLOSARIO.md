######  Agent
Sistema de IA capaz de planificar tareas, tomar decisiones y ejecutar acciones mediante **herramientas externas** para conseguir un objetivo. Puede utilizar LLMs pero no son lo mismo.

###### Fine-tuning
Proceso de **ajustar** un modelo previamente entrenado utilizando datos adicionales.

###### Inference
(deducir) Proceso mediante el cual un modelo utiliza lo aprendido para generar una respuesta o realizar una tarea.

###### LLM
Modelo de IA entrenado con **grandes cantidades de texto** con el fin de aprender patrones del lenguaje y generar respuestas mediante probabilidad.

###### Open weight
Modelo de IA cuyos **pesos** (**parámetros**) están disponibles **públicamente** para terceros.

###### Prompt
Instrucciones o información que se proporcionan a un modelo para inferir en una respuesta.

###### Token
Unidad de texto en la que un modelo **divide** la información para procesarla.
